编译与启动

需要 Python 3.9+、.NET SDK 8+ 和本机的 Windows Steam 版星露谷 1.6.15。首次编译从 NuGet 获取 net6.0 引用包；运行时使用游戏自带的 .NET 6。

git lfs install
git clone https://github.com/ffffhx/stardew-valley-assets.git
cd stardew-valley-assets
git lfs pull
python reconstruction/run.py all --game "D:\Steam\steamapps\common\Stardew Valley"

--game 换成你的安装目录。启动器校验原始主程序集 SHA-256，复制内容到 reconstruction/runtime，用本工程编译出的两个 DLL 替换副本，再作为独立进程启动。默认存档和设置保存在 reconstruction/runtime-data。

单独编译、重新启动与自动验证
# 仅编译；SDK 不在 PATH 时可追加 --dotnet "...\dotnet.exe"
python reconstruction/run.py build --game "你的游戏目录"
# 准备运行副本
python reconstruction/run.py prepare --game "你的游戏目录"
# 打开已准备好的重建版
python reconstruction/run.py launch --game "你的游戏目录"
# 创建独立测试农场，执行验证，完成后留在游戏窗口
python reconstruction/run.py all --game "你的游戏目录" --smoke-test

修改代码后先关闭此前的重建游戏，再重新编译和准备，避免覆盖正在使用的 DLL。日志在 reconstruction/logs；每次自动验证的报告、画面与存档在 reconstruction/test-data/时间戳。

目录与平台差异

source/：原始反编译代码；reconstruction/src/：修复后工程；assets/：解包图片、地图和数据；audio/：WAV；run.py：构建与独立启动。运行副本、临时日志和测试存档不提交到 Git。

Windows 已实测。macOS 需要同版本的 macOS 游戏依赖和 apphost，不能复用 Windows 原生运行文件；可用 STARDEW_GAME_PATH 或 -p:GamePath=... 提供依赖路径，macOS 编译及运行均未验证，自动启动功能目前仅用于 Windows。
